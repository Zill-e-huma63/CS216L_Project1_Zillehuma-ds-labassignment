# Student Record System

## Project Description

Student Record System is a Java-based project used to manage student records. It allows users to add, search, display, and manage student information using data structures.

## Data Structures Used

* Linked List
* Stack
* Node

## Features

* Add student records
* Display student records
* Search student records
* Delete student records
* Stack-based student record management

## Time Complexity

| Operation        | Time Complexity |
| ---------------- | --------------- |
| Add Student      | O(1)            |
| Search Student   | O(n)            |
| Display Students | O(n)            |
| Delete Student   | O(n)            |
| Stack Push       | O(1)            |
| Stack Pop        | O(1)            |
